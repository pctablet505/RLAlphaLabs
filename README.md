# RL Alpha Labs

**A research lab testing trading ideas on Indian equities.** Research stage, paper trading only: no real money is traded.

**Live site:** https://rlalphalabs.com/

The site is built around one real test: can an AI model that reads company filings beat a numbers-only forecast? The answer so far is almost a tie, so the lab closed the idea. The site lists the ideas the lab has closed and the reason for each.
